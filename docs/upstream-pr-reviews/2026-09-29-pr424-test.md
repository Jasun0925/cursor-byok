原错误为：

```text

```

`otool -l` 显示该库的 `LC_SYMTAB.stroff=6481748`，不能被 8 整除。macOS 在加载宏库时拒绝此产物，随后出现的 SQLx unresolved imports 是后续编译错误；此时测试根本没有执行。此前清理并重建 sqlx-macros 包缓存仍复现。

仅切换 Rust 自带的 LLVM 链接器也不够：它不能解析 macOS 27 SDK 的 `arm64e.x1-macos` 架构标记，报 `could not load TAPI file ... unknown architecture`。本机改用现成的 26.5 SDK 后编译和测试成功。

这是针对本机工具链组合验证过的构建方法，不表示已经证明 Apple 链接器内部的具体缺陷，也未升级或修复系统工具链本身。

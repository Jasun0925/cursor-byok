
```text
用户输入 → 编译一次 → 同一 run 发 HTTP 请求
                      ├─ 无内容的 503 → 等 5 秒 → 重发相同请求
                      └─ 已有部分文字后断流 → 保存部分文字和继续提示
                                             → 从追加后的历史重试
后续 Resume → 新 run → 恢复 checkpoint → 使用此前保留的文字与工具结果
```

无内容的 503 不应增加任何提示；带部分文字的断流则允许追加该次保留的文字和继续提示，这与重复注入模式提示不同。旧历史仍需保持前缀稳定。

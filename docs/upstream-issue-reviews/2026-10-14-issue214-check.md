## 当前执行边界

```text
server/src/
├── run/model_cycle.rs                    # 检查模型是否正常结束、是否达到输出长度限制
├── run/engine.rs                         # 根据工具调用与新消息决定继续或结束 run
└── cursor/tools/tool_call_result/local.rs # 将 TodoWrite 内容返回模型并生成 Cursor 待办卡片
```

- 模型正常返回且没有后续工具调用时，engine 写入回复、处理等待中的新消息；若无继续输入，发布 checkpoint 并结束本次 run。
- 这一结束分支没有用 todo 是否全部完成作为继续运行的条件。TodoWrite 的成功只表示待办更新成功，不能证明任务已经完成。
- 达到输出长度限制（FinishReason::Length）在 model_cycle 中报错；没有 Done 的断流也报错，不直接当成正常完成。
- 因此“待办还没完成就停下”可能是模型主动结束，也可能是截断或中断；仅根据 UI 待办状态无法区分，更不能据此强制无限续跑。

## 最小复现方向

使用隔离工作区布置有明确完成标准的多步任务，记录停止前的待办、已完成文件/命令、最后一次模型响应的 finish_reason、工具调用和 run 结束状态。优先捕获用户日常可用模型的实际提前停止；若无法使用原 opencode-mimo-v2.5，只能证明本次所测模型的行为。先确认失败发生在哪一层，再决定是否需要修复。

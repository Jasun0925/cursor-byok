# Issue #310：允许模型不发送 OpenAI 推理参数

> 历史记录：状态、版本、路径及测试数仅对应记录日期；当前交付状态见 [工作状态](../../work-status.md)。复现脚本按文中基线使用，不作为当前生产操作步骤。

## 结论

上游 [#310](https://github.com/leookun/cursor-byok/issues/310) 报告 DeepSeek R1 拒绝 `reasoning_effort=medium`。原界面的“推理强度：不设置”只是不保存默认值；如果 Cursor 的请求本身带了 `medium`，服务端仍会沿用并发送该字段。

本次增加了明确的 **“不传入”** 选项。它保存为模型配置的 `reasoning_effort=none`，服务端在配置模型时会清除 Cursor 请求中的 effort，并关闭 reasoning；OpenAI Chat provider 因而不会生成 `reasoning_effort` 字段。

## 执行路径

```text
CursorModelEditor
  → 推理强度 = 不传入
  → ModelConfig.reasoning_effort = "none"
  → ModelConfig::configure
  → 清除 RequestedModel 的 effort/enabled
  → OpenAI Chat apply_model
  → 请求体不包含 reasoning_effort
```

改动文件：

```text
apps/desktop/src/features/models/CursorModelEditor.tsx # 增加“不传入”选项
apps/desktop/src/i18n/                           # 新增中/英/葡萄牙语文案
server/src/model/configuration.rs                 # 解析 none 并覆盖 Cursor 请求
server/src/provider/openai_chat.rs                # 增加缺省字段回归测试
```

# Issue #294：文本模型历史回放移除图片输入

> 历史记录：状态、版本、路径及测试数仅对应记录日期；当前交付状态见 [工作状态](../../work-status.md)。复现脚本按文中基线使用，不作为当前生产操作步骤。

## 结论

Issue #294 的现版实现已补充模型级 **“移除图片输入”** 配置。开启后，模型请求发往 provider 前会从所有 provider-visible 的普通消息中移除图片块；原始会话和 checkpoint 不变，因此视觉模型可以继续保持原行为，文本模型也不会在每轮历史回放中再次看到粘贴图片。

## 执行路径

```text
CursorModelEditor
  → 移除图片输入 = 开启
  → ModelConfig.strip_images 入库
  → ModelConfig::configure
  → ModelSpec.strip_images
  → ProviderRouter
  → provider history projection 移除 ContentPart::Image
  → Anthropic/OpenAI provider 只收到文本块
```
